🌐 Company Favicon

Custom favicon per company - Branding made easy!

🎯 Compatibility

✅ Odoo 18.0 ✅ Odoo 17.0

Works with both Community and Enterprise editions

✨ Features

  • Custom favicon per company - Upload unique favicon for each company
  • Automatic favicon change - Favicon updates instantly when switching companies
  • Multiple format support - PNG, ICO, SVG, and GIF formats supported
  • Instant preview - See your favicon immediately in company settings
  • Multi-company ready - Perfect for organizations with multiple companies
  • Persistent storage - Favicon stored securely in database
  • Fallback support - Uses default Odoo favicon if none uploaded

📋 How to Use

  1. Go to Settings → Users & Companies → Companies
  2. Select the company you want to customize
  3. Scroll down to the "Favicon" section
  4. Upload your favicon image
  5. Save - The favicon updates automatically in your browser tab!
💡 Pro Tip: For best results, use a square PNG image with 32x32 or 16x16 pixels and transparent background.

🏢 Multi-Company Support

Each company in your Odoo instance can have its own unique favicon. When users switch between companies, the browser favicon automatically updates to match the current company's branding.

This is perfect for:

  • Organizations with multiple brands
  • Franchise businesses
  • Holding companies with subsidiaries
  • Service providers managing multiple client companies

⚙️ Technical Details

  • Extends res.company model with binary favicon field
  • HTTP controller serves favicon at /web/company/<id>/favicon
  • JavaScript service monitors company changes using OWL framework
  • Automatic content-type detection (PNG, ICO, SVG, GIF)
  • Browser cache optimization with proper cache headers
  • Graceful fallback to default Odoo favicon
⚠️ Version Requirement This module uses the OWL framework service registry which is only available in Odoo 17.0 and later. Not compatible with Odoo 16.0 or earlier versions.
